## Why this unit
Nothing in the app reads the outline or follows a link today (P1 listed bookmarks but shipped thumbnails/search/labels; the renderer has no outline or link code). Unit 3 measured that deleting a page leaves outline entries and GoTo links naming a page that no longer exists, plus a phantom AcroForm field, and MuPDF prints `cannot find page N` on the next page-tree load. This unit gives the user the navigation layer (keyboard-complete), lets them add/rename/delete bookmarks and add/delete links through the journal, and makes `page-delete` leave a consistent document.

## Decisions (fixed)
- **Outline ops.** `{op:'outline'}` → `{ok, items:[{id, title, depth, page: number|null, uri?: string}]}` in preorder; `id` = preorder index in that reply; `page` from `resolveLink` on the item's uri, `null` when it has no destination or the destination is external (then `uri` is given). `{op:'outline-add', title, page}` appends a top-level entry with a `Fit` destination to `page` (`formatLinkURI`). `{op:'outline-set', id, title}` renames. `{op:'outline-delete', id}` deletes the entry **with its subtree** (stated). Titles: non-empty after trim, ≤ 4096. Nested add and reorder are deferred. One journal operation each (`"add bookmark"`, `"rename bookmark"`, `"delete bookmark"`).
- **Link ops.** `{op:'links', page}` → `{ok, page, items:[{id, rect, kind:'page'|'uri'|'blocked', page?, uri?}]}`; `id` = index in `getLinks()` order for that reply; `kind:'page'` when `resolveLink` yields a page; `'uri'` only for `http:`, `https:`, `mailto:`; everything else (`file:`, `javascript:`, launch, unknown) is `'blocked'` and is never followed or opened. `{op:'link-add', page, rect, target:{page:number}|{uri:string}}` → `createLink(rect, uri)`; a `uri` target is refused unless its scheme is on the same allowlist; `rect` must lie inside the page box (unit 2 geometry refusal). `{op:'link-delete', page, id}`. One journal operation each (`"add link"`, `"delete link"`).
- **Repair inside `page-delete`.** The same `mutate("delete page")` also: (1) sets `uri` to undefined (title kept, subtree kept) on every outline entry whose destination resolves to the removed page; (2) deletes every link on a surviving page whose destination resolves to the removed page; (3) removes from `/AcroForm /Fields` any field left with no widget in the file. One undo restores all of it. **Gate (ds2 measures first, tests before code):** outline iterator `insert`/`update`/`delete`, `createLink`/`deleteLink` and the `/Fields` edit must all be covered by the journal; if any is not, stop and hand off with the measurement. After a repaired delete the next page-tree load must print nothing to stderr.
- **Following links.** Activating a `'page'` link or an outline entry calls the renderer's `goTo`. Activating a `'uri'` link sends `open-link {uri}` to main; main re-checks the allowlist, shows a native confirm ("Open <uri> in your browser?" Open/Cancel), then `shell.openExternal`. In smoke mode main never opens anything and logs `P2_LINK {"uri":…,"allowed":bool}` instead. `'blocked'` links have no action and show "Blocked link (<scheme>)".
- **Panels (semantic path).** `<section id="outline" aria-labelledby="outline-heading">` "Bookmarks": a nested `<ul>` (one `<li>` per entry, indentation by `depth`, a `<button>` with the title that navigates, "Rename" and "Delete" buttons per entry), an "Add bookmark" button that opens a dialog like the note dialog (title prefilled "Page n") and adds for the current page. `<section id="links" aria-labelledby="links-heading">` "Links on page n": one row per link ("Page 3" / the URI / "Blocked link (file:)"), "Go"/"Open" and "Delete" buttons; "Link to page…" and "Web link…" buttons take the rect from the **current search hit** (quad union, like markups; disabled with no hit) and a dialog for the page number or URL. `role="status"` line: "Added bookmark Page 3", "Renamed bookmark", "Deleted bookmark", "Added link to page 3", "Deleted link". Both panels refresh from `outline`/`links` after every edit, undo/redo and page op.
- **Menu (grok).** Insert → "Bookmark…" ⇧⌘B and "Link to Page…" ⇧⌘K send `edit-request {op:'bookmark'}` / `{op:'link'}`; the renderer opens the same dialogs.
- **Fixture (grok, seam first):** `fixtures/nav.pdf` from stdlib `fixtures/make-nav.py` (+ provenance JSON in the `form2` shape): three 612×792 pages with texts `one`, `two`, `three` (Helvetica 24 at 72,700 like `textpages.mjs`); outline `One`→p1, `Two`→p2 with child `Two-A`→p2, `Three`→p3 (`/Count` correct, page destinations as indirect refs with `/Fit`); links: p1 rect [72 680 200 730] GoTo→p2, p1 rect [72 600 300 630] URI `https://example.com/`, p3 rect [72 680 200 730] GoTo→p2, p3 rect [72 600 300 630] URI `file:///etc/hosts` (the blocked one). No `/OpenAction`, no JavaScript.
- Read-only rule unchanged (signed, certified, encrypted refuse). Values are the user's; nothing else is written.
