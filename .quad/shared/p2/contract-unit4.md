## Why this unit
Filling a form is the most common edit a reader makes. Widgets already exist on the page; this unit exposes them as native inputs in a side panel (the keyboard path), writes values through the journal spine, regenerates appearances so Preview shows them, and warns — never silently — on fields that depend on scripts this app does not run.

## Decisions (fixed)
- Field kinds this unit: text (single/multiline, `MaxLen`), checkbox, radio group, combo box, list box (single select). Signature fields are listed but not fillable ("sign in a later version"); push buttons are omitted; read-only fields (`Ff` bit 1) are shown disabled.
- Ops: `{op:'fields', page}` → `{ok, page, items:[{id, name, label, kind:'text'|'checkbox'|'radio'|'combo'|'list'|'signature', value, options?, maxLen?, multiline?, readOnly, scripted, on?}]}`; `id` = widget object number; radio kids are separate items sharing `name`, each with its `on` export value and `value: boolean`; `{op:'field-set', page, widgetId, value}` → text: `setTextValue` (string ≤ 4096 and ≤ `MaxLen` when > 0, else refuse); combo/list: `setChoiceValue` (must be one of `getOptions()`; a free-text combo is a stated limit, refuse); checkbox/radio: `value: boolean`, `toggle()` only when the current state differs (radio `true` on a kid turns the group to that kid; `false` on a radio is refused). One journal operation `"fill field"` per set, then `update()`. Reply is the unit 1 slice.
- `scripted` is true when the widget or its field dictionary has `/AA` containing any JavaScript action (`/S /JavaScript`), or the field is named in `/AcroForm /CO`, or the document has `/Names /JavaScript` (document-level scripts). The renderer shows "Runs a script this app does not execute; the value is saved as typed" on such rows and once at the top of the panel when any field is scripted. Nothing is computed or formatted on their behalf.
- Appearances: `widget.update()` after every set; never set `/NeedAppearances`. Preview must show the typed value with no help (Quick Look pixel proof like unit 2). Non-Latin text in a `/Helv` field is a stated limit.
- Values are the user's; nothing personal is written beyond them (no `/T` author, no machine/user name, no timestamps we add).
- Read-only rule unchanged: signed, certified, encrypted documents refuse (permission-aware fill of signed forms is P5).
- The panel is the semantic path: `<section id="fields" aria-labelledby="fields-heading">` "Form fields on page n", one `<label>`+control per item, native `<input type=text|checkbox>`, `<textarea>`, `<select>`, radio `<fieldset>`; commit on `change` (text on blur/Enter), one `field-set` per commit; undo/redo/page-op refresh the panel from `fields`.
- Fixture (grok, seam first): `fixtures/form2.pdf` from a new deterministic stdlib `fixtures/make-form2.py` in the style of `make-form.py`, with provenance JSON in the same shape (the provenance test must pass): fields `name` (text, `MaxLen` 20, `/V ()`), `notes` (multiline text), `agree` (checkbox, on-state `/Yes`), `size` (radio: kids `/S`, `/M`, `/L`), `choice` (combo: one two three), `pick` (list box: alpha beta gamma), `fixed` (read-only text `/V (locked)`), `amount` (text with `/AA << /F << /S /JavaScript /JS (AFNumber_Format(2,0,0,0,"",true)) >> >>` and listed in `/AcroForm /CO`), `sig` (unsigned signature field). All on one 612×792 page with visible captions so Preview screenshots read; `/DA /Helv 12 Tf 0 g`, `/NeedAppearances` absent.

## A. Engine / worker / renderer (ds2) — `src/renderer/*`, `tests/p2-forms.test.mjs`
1. `fields` and `field-set` as above; `kind` from `getFieldType()`/`is*()`; `value` from the field (measure which accessor this build exposes; `/V` via `getObject()` is the fallback); `scripted` per the rule; validation before one `mutate`; refusals never dirty.

3. Smoke hooks: `edit-request {op:'form', contents}` fills `name` with `contents`, checks `agree`, picks combo `two`, radio `/M`, then logs `P2_EDIT {…, "fields":{"count":n,"scripted":m,"values":{"name":…,"agree":true,"size":"M","choice":"two"}}}` (fixed key). Undo/redo log the same line.
4. Tests: form.pdf (one text field) and form2.pdf listing with kinds/flags/`scripted` (true only for `amount`); set each kind; refusals (over `MaxLen`, not an option, read-only field, signature, radio false, bad id, read-only document); undo/redo restore values; save → validate → reopen keeps values and every set widget has `/AP`; hello.pdf lists nothing; large.pdf `fields` cost.
