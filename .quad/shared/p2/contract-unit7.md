# P2 unit 7 — New documents and exports: images → PDF, page → PNG/JPEG, text → .txt

Self-contained: read `contract-unit6.md` first (same seats, same **parallel rule**: grok owns `src/main.ts`, `src/preload.cts`, `src/safe-write.ts`, `scripts/`, `fixtures/`, `tests/p1-*.test.mjs`; ds2 owns `src/renderer/*`, `tests/p2-*.test.mjs`; never edit the other seat's files), then `contract-unit1.md`, `contract-unit5.md` (P1 print unit: raster at 150 DPI through our engine). Baseline 122/122 plus whatever unit 6 lands. grok starts §B here right after unit 6 §B; ds2 starts §A after unit 6 §A. No new dependencies, no nested agents, never `--no-sandbox`, no PDF JavaScript ever runs.

## Why this unit
P2 exit lists image→PDF and basic exports. Everything needed is already in the app: the engine renders pages to pixels (print), the renderer has extracted text, mupdf builds documents (`PDFDocument()`, `addImage`, `addPage`), and `OffscreenCanvas.convertToBlob` encodes PNG/JPEG natively. Nothing here touches the open document's journal.

## Decisions (fixed)
- **New-file write path (grok).** Preload `saveNew(bytes:ArrayBuffer, suggestedName:string, kind:'pdf'|'png'|'jpeg'|'txt'): Promise<{ok:true, name} | {ok:false, reason:'cancelled'|'too-large'|'unreadable'|'busy'}>` → main `save-new` IPC: trusted sender, `kind` fixed set, `suggestedName` basename ≤ 255 with the kind's extension enforced, bytes ≤ 50 MiB (save ceiling), native Save dialog with the kind's filter, then `safe-write.ts` `writeNew(dest, bytes)` (exclusive temp in the dest dir + fsync + rename, same journal as `saveCopy`, no source file). Smoke: `--save-to` is the destination. Then, for `kind:'pdf'` only and when the renderer asks (`open:true` field), main delivers the written file through the existing open path (`deliverOpen(path)`) so the new PDF becomes the open document.
- **Image picker (grok).** Preload `pickImages(): Promise<{ok:true, images:[{name, bytes:ArrayBuffer}]} | {ok:false, reason}>` → main `pick-images` IPC: native open dialog, multi-select, filters png/jpg/jpeg, ≤ 50 files, each ≤ 32 MiB, total ≤ 120 MiB, read into memory; no path leaves main. Smoke: `--images=<abs>,<abs>` answers the dialog.
- **Engine `pdf-from-images` (ds2).** `{op:'pdf-from-images', images:[{name, bytes}]}` → new `PDFDocument()`; per image `new Image(bytes)` (refuse anything mupdf cannot decode as PNG/JPEG; name it in the error), `addImage`, one page per image with mediabox = image pixel size × 72 / (image DPI if present, else 72), each edge clamped to 14400 pt (scale the page, not the image), contents `q W 0 0 H 0 0 cm /Im0 Do Q`, `saveToBuffer` → `{ok, bytes, pageCount}` transferred. Never touches the open session. Order = picker order.
- **Page image export (ds2).** Renderer-side: the engine's existing `render` at `scale = dpi/72` (DPI choices 72/150/300, default 150; same cap as print: a page above 40 MiB of pixels is refused with the print message) → `OffscreenCanvas` → `convertToBlob({type:'image/png'})` or `{type:'image/jpeg', quality:0.9}` → `saveNew(bytes, '<stem> page 3.png', 'png'|'jpeg')`. Works on read-only and encrypted-unlocked documents only if `hasPermission('print')` is true (same rule as print).
- **Text export (ds2).** `{op:'text-all'}` → `{ok, text}`: every page's structured text as plain lines, pages joined by `\f`; ≤ 50 MiB else refused. Renderer: `saveNew(utf8 bytes, '<stem>.txt', 'txt')`. Same permission rule as copy: allowed unless the document forbids copying (`hasPermission('copy')` false) — **decision: honour the copy bit.**
- **Renderer UI (semantic path).** File-menu-driven (grok items), plus buttons in the header next to "Save a copy…": "Export…" opens `<dialog id="export-dialog">` with a `<select id="export-kind">` (Current page as PNG / Current page as JPEG / All text as .txt) and a `<select id="export-dpi">` (72/150/300, disabled for text) → Export. "New from images…" button next to "Open…" (enabled always) → `pickImages` → `pdf-from-images` → `saveNew(..., 'pdf', open:true)` → the file opens. Status: "Exported page 3 as PNG (1275×1650)", "Exported text (12 pages)", "Created images.pdf (2 pages)".
- **Menu (grok).** File → "New from Images…" ⌥⌘N, "Export…" ⌥⌘E is taken by unit 6 → use ⇧⌘E. Send `edit-request {op:'new-from-images'}` / `{op:'export'}`.
- **Smoke (grok flags, ds2 hooks).** `--edit=export-png|export-jpeg|export-txt` with `--save-to`: renderer exports page 1 at 150 DPI (or all text) and logs `P2_EDIT {…, export:{kind, bytes, width?, height?, pages?}}`; main ok iff `--save-to` exists with the right magic bytes (`\x89PNG`, `\xFF\xD8`, or UTF-8 text containing the fixture's text). `--new-from-images --images=a,b --save-to=<pdf>`: no `--open`; renderer builds and saves; main ok iff the file exists and `P2_NEW {pages:2, bytes}` was logged; then the smoke exits (it does not reopen in smoke).
- **Fixtures (grok).** `fixtures/make-images.py` (stdlib zlib PNG writer): `img-rgb.png` 300×200 RGB gradient, `img-gray.png` 200×300 grayscale with a black band at rows 100–120, provenance JSON each. No JPEG fixture: JPEG is proven by exporting a page as JPEG and feeding that file back through `--new-from-images` in a test.
