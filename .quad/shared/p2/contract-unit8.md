# P2 unit 8 — Page decoration and metadata: watermark, header/footer, page labels, layer visibility

Self-contained: read `contract-unit6.md` (seats, **parallel rule**: grok owns `src/main.ts`, `src/preload.cts`, `src/safe-write.ts`, `scripts/`, `fixtures/`, `tests/p1-*`; ds2 owns `src/renderer/*`, `tests/p2-*`), `contract-unit3.md` (page ops, `applyPageEdit`, `PAGE_STEPS`), `gate-unit8.md` + `gate-unit8.mjs` (fable51 measured: an appended content stream and `setPageLabels` are journaled, undo restores, both survive save + reopen). Baseline = whatever unit 7 closes at. No new dependencies, no nested agents, never `--no-sandbox`, no PDF JavaScript ever runs. Start this only after your unit 7 hand-off.

## Why this unit
P2 lists watermark/header/footer, labels and layers. All three are cheap on top of the journal: a stamp is one appended content stream per page, labels are one `setPageLabels` call, layers are `setLayerVisible`. The only open measurement is whether a layer toggle is persisted or view-only (ds2 gate inside the unit).

## Decisions (fixed)
- **Stamps.** `{op:'stamp', kind:'watermark'|'header'|'footer', text, pages?:number[]}` (default all pages; `text` 1–200 chars, WinAnsi-encodable only, else refused naming the first bad character). Per page, in one `mutate("add watermark"|"add header"|"add footer")`: prepend a stream `q\n` and append a stream `Q\n<stamp>` to `/Contents` (array form), so the page's own graphics state cannot leak into the stamp. Font: `addSimpleFont(new Font("Helvetica"))`, referenced (not embedded) from the page's `/Resources /Font` under a fresh key `/PDF4AllF`. Watermark: 48 pt, 50 % grey (`0.5 g`), rotated 45° about the page centre, centred (`Tw`-free: measure with `Font.advanceGlyph` or approximate 0.5 em per char — approximation accepted, stated). Header: 10 pt black at 36 pt from the visual top, left margin 36 pt; footer: same at 36 pt from the visual bottom. **Honour `/Rotate`**: positions are computed in the unrotated page space so header/footer land at the *visual* top/bottom (0/90/180/270). Placeholders in header/footer text: `{page}` (1-based index), `{pages}`, `{label}` (page label, falls back to the index). The stamp is wrapped `/PDF4All <</Kind /Header>> BDC … EMC` so a later unit can find and remove it; **removal is undo only in this unit (stated)**.
- **Labels.** `{op:'labels'}` → `{ok, items:string[]}` (`getLabel()` per page). `{op:'labels-set', from, style:'D'|'r'|'R'|'a'|'A'|'', prefix?:string(≤32), start?:number(≥1)}` → `setPageLabels(from, style, prefix, start)` in one `mutate("set page labels")`. `{op:'labels-clear', from}` → `deletePageLabels(from)`, `mutate("clear page labels")`. The renderer shows the label wherever it shows a page number when the label differs from the index: `#status` "Page 3 (iii) of 5", thumbnails' `aria-label`, `#page-nav` label. Undo of a labels op refreshes labels (add both step names to a `LABEL_STEPS` set or fold into `PAGE_STEPS`).
- **Layers.** `{op:'layers'}` → `{ok, items:[{id, name, visible}]}` via `countLayers/getLayerName/isLayerVisible`. `{op:'layer-set', id, visible}` → `setLayerVisible`, then the renderer re-renders the page and thumbnails (`cache.clear()`). **Gate (ds2, first):** is `setLayerVisible` journaled, and does `saveToBuffer` write the change (`/OCProperties /D /ON|/OFF`)? If journaled and written → `mutate("set layer visibility")`, dirty like any edit. If view-only → no journal, no dirty, the panel says "(view only, not saved)". Write the answer in `p2-decorate.md`; either outcome ships.
- **Renderer UI.** `#page-tools`: "Watermark…", "Header/footer…", "Page labels…" buttons (writable doc only) opening `<dialog id="stamp-dialog">` (kind select, text input, "Pages" range blank = all, live hint "Placeholders: {page} {pages} {label}") and `<dialog id="labels-dialog">` (from page, style select with the five styles + "none", prefix, start; "Clear from this page" button). New `<section id="layers">` "Layers" with one checkbox per layer (hidden when `countLayers() === 0`). Status lines in `#page-status`: "Added watermark to 3 pages", "Added header to 3 pages", "Page labels set from page 1", "Cleared page labels from page 1", "Layer Notes hidden".
- **Menu (grok).** Page → "Watermark…" ⌥⌘W, "Header and Footer…" ⌥⌘F (⌥⌘H is macOS Hide Others), "Page Labels…" ⌥⌘L → `edit-request {op:'watermark'|'header-footer'|'labels'}`.
- **Fixture (grok, seam first).** `fixtures/make-layers.py` → `layers.pdf` (+ provenance): one 612×792 page, `/OCProperties << /OCGs [A B] /D << /Order [A B] /ON [A B] >> >>`, OCG A `/Name (Base)`, B `/Name (Notes)`; page content draws `base` inside `/OC /ocA BDC … EMC` at 72,700 and `notes` inside `/OC /ocB BDC … EMC` at 72,600 (Helvetica 24, `/Properties` resources). Text extraction of the page = `base` + `notes`.
- **Smoke.** `--edit=decorate` on the open doc (contents = `PDF4All P2 decorate`): watermark `contents` on all pages, header `Page {page} of {pages}` on all pages, labels from page 1 style `r`; if the doc has layers, hide layer 1 (`Notes`). Log `P2_EDIT {…, decorate:{stamps:{watermark:n, header:n}, labels:[…], layers:[{name, visible}], layersSaved:bool}}`. main ok iff `stamps.watermark === stamps.header === pages.count`, `labels[0] === 'i'`, and on layers.pdf `layers[1].visible === false`; undo (one step = the last op) ok iff the undone item reverted (labels back to `'1'` when labels was last — order the smoke so labels is the last op unless a layer op was journaled, then that is last and undo checks `layers[1].visible === true`).
- **Verify (grok).** `verify-roundtrip.py --labels '["i","ii","iii"]'` (pypdf `page_labels`), `--text-has '{"0":["PDF4All P2 decorate","Page 1 of 3"]}'` (pypdf `extract_text` contains each string), `--layers '[{"name":"Base","on":true},{"name":"Notes","on":false}]'` (`/OCProperties /D /ON|/OFF` membership by name; used only when the gate says layers are saved).
