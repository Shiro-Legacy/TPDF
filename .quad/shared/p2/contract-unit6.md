## Why this unit
The P2 exit says "assemble … reopen correctly elsewhere, including merges with colliding form names/outlines". Unit 3 reorders and deletes pages inside one file; nothing brings pages in from another file or writes a page range out. This unit adds both through the journal (insert) and through a fresh document (extract), and measures what a merge does to AcroForm field names.

## Decisions (fixed)
- **Source bytes.** Preload `pickInsertSource(): Promise<{ok:true, name, bytes:ArrayBuffer} | {ok:false, reason:'cancelled'|'too-large'|'unreadable'}>` → main `insert-source` IPC: trusted sender, native open dialog (PDF filter), read with the open ceiling (120 MiB) into memory, no path leaves main, no second document is "opened" (title, `openPaths`, dirty state untouched). Smoke: `--insert-from=<abs pdf>` answers the dialog.
- **Engine `insert-pages`.** `{op:'insert-pages', pdf:ArrayBuffer, name, at:number, pages?:number[]}` → `at` is the 0-based index the first inserted page takes (`0..pageCount`), `pages` are 0-based source indices (default all, ≤ 2000, each valid, duplicates allowed). Source opened with `new PDFDocument(bytes)`; refused (never dirty) when it is not a PDF, needs a password, or has zero pages; `disableJS` stays on the target as today. Pages come across with `graftPage(to, src, srcPage)` in one `mutate("insert pages")`. Reply = `editState` + `pageCount` + `pages` like the unit 3 ops. **Gate (ds2, tests before code):** `graftPage` must be journaled and one undo must remove every inserted page. Measure and write down: does a grafted widget land in `/AcroForm /Fields`? If not, the same operation appends each grafted top-level field to `/Fields` (else pypdf `get_fields` and Preview never see them). If a grafted top-level field's `/T` collides with an existing one, rename the grafted one `<name> (2)` (`(3)`, …) in the same operation, so no two top-level fields share a name. Source bookmarks are **not** merged (stated limit); links on grafted pages that pointed inside the source resolve or dangle as mupdf leaves them, measured and written in `p2-assemble.md`, not fixed.
- **Engine `extract-pages`.** `{op:'extract-pages', pages:number[]}` (0-based, ≤ 2000, order kept, duplicates allowed) → a new `PDFDocument()`, `graftPage` each, `saveToBuffer` with the same options as `save`, reply `{ok, bytes, pageCount}` (transferred). Not a mutation: journal, dirty, revision untouched. Refused on a locked document; the read-only rule for signed/certified/encrypted stays (extracting from them is allowed, it writes nothing into them — **decision: allowed**, since it is a copy).
- **Saving the extract.** Renderer calls `api.saveFile(bytes, doc.url, { suggestedName })` (grok adds `suggestedName`: string, basename only, ≤ 255, `.pdf` enforced; ignored for in-place). Default `<stem> pages 2-4.pdf` (the page list compacted into ranges). Smoke `--save-to` is the destination as today. The open document's dirty/saved state is not touched by an extract.
- **Renderer UI (semantic path).** In `#page-tools`: "Insert pages…" and "Extract pages…" buttons (disabled read-only / no doc; extract enabled on read-only). Insert: pick source via preload, then `<dialog id="insert-dialog">` "Insert N pages from <name>" with "After page" `<input type=number>` (default current page; 0 = before the first) and "Pages" text input (default blank = all; reuse the print range parser) → `insert-pages`. Extract: `<dialog id="extract-dialog">` with "Pages" (default current page) → `extract-pages` → `saveFile`. Status lines (`#page-status` role=status, existing): "Inserted 3 pages after page 1", "Extracted 2 pages to <name>". Thumbnails, panels and the page count refresh via `applyPageEdit` like unit 3.
- **Menu (grok).** Page → "Insert Pages from File…" ⌥⌘I, "Extract Pages…" ⌥⌘E → `edit-request {op:'insert'}` / `{op:'extract'}`.
- **Smoke (grok flags, ds2 hook).** `--edit=assemble --insert-from=<pdf>`: renderer inserts **all** pages of the source after page 1, logs `P2_EDIT {…, pages:{count,rotate}, fields:{count,…}, assemble:{inserted:n, source:name, fieldNames:[…top-level /T…]}}`. main ok iff `pages.count === opened.pageCount + inserted` and `fieldNames` has no duplicates; undo ok iff `pages.count === opened.pageCount`. `--edit=extract`: renderer extracts page 2 (0-based 1) and saves to `--save-to`; logs `P2_EDIT {…, extract:{pages:[1], bytes}}`; main ok iff `--save-to` exists and `extract.pages` is `[1]`; not combinable with undo.
- **Fixtures.** None new. Merge test = insert `form2.pdf` into `form2.pdf` (9 colliding names → 18 fields, unique after rename); nav test = insert `nav.pdf` into `hello.pdf`; extract from `nav.pdf`.
