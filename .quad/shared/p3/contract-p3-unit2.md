## 1. Deliverable
A candidate text target from U1 (`edit-targets`, `support:"candidate"`, `kind:"text"`) can be **replaced or deleted** from the Text inspector. The operator's operand bytes are rewritten in place in the stream that holds them; nothing is overlaid. Old content is gone from the saved file. Neighbours, tags, links and other placements are untouched. Shared targets stay refused until U1b lands (its probe runs in this unit; integration is U1b's own brief).

## 2. Engine seam (ds2)
`EditTextRequest = { id, op:"edit-text", page, targetId, generation, revision, text }`; `text:""` deletes (the operator becomes `() Tj`, ActualText becomes `()`; the empty operator is kept so byte spans elsewhere stay valid).
Success reply: `{ id, ok:true, page, ...editState }` — the renderer re-requests `edit-targets` (ids change after a rewrite).
Refusal reply: existing `ok:false` shape plus `detail` = one fixed token: `stale-target`, `not-candidate` (carries the U1 `reason`), `unsupported-encoding` (with `missing:[chars]`), `overflow`, `tail-would-move`, `unmeasurable-width`, `ambiguous-text-association`, `too-large`. Refusals never open an operation.

Order inside the case: `requireMutable(session,"edit-text")` (default `edit` permission) → `resolveEditTarget` → record must be `kind:"text"` and `candidate` → text validation → width gate → tag gate → one `mutate(session, doc, "edit text", …)` doing every byte write → return.

### Text validation
- `typeof text === "string"`, length ≤ 4096, every char in `0x20..0x7E` (same cut as U1 discovery); otherwise `unsupported-encoding` listing the offending chars (max 20). Escape `\`, `(`, `)` when writing the literal; write a literal string, never hex, so U1 re-finds it.
### Width gate (the "no reflow" rule made concrete)
- Measure old and new advance with the run's own font: during the U1 structured-text walk the `onChar` font handle is live; compute `Σ font.advanceGlyph(font.encodeCharacter(ch), 0) × size` for both strings in the same walk. `encodeCharacter` returning 0 for any new char → `unsupported-encoding` with `missing`. Unmeasurable (no font handle, non-finite) → `unmeasurable-width`.
- U2 adds `tailFollows:boolean` to `EditTargetRecord`: true when another `Tj/TJ/'/"` follows this operator inside the same `BT…ET` with no `Td/TD/Tm/T*` between them (the tail's origin depends on this run's advance).
- Rule: `tailFollows` → |new − old| ≤ 0.5 pt else `tail-would-move`. Not `tailFollows` → new ≤ old + 0.5 pt else `overflow`. Shorter text leaves a gap; the UI says so before Apply. Report `oldWidth/newWidth` in the refusal.
- **Amendment 23:00 (ds2 m87):** Helvetica `BRAVO` is 2.66 pt wider than `ALPHA` at 12 pt, so the rule refuses the P0-b example. The rule stands (parent §2: refuse overflow). The U2 success example is **`ALPHA` → `BETA`** (2612 vs 3279 /1000 em: shorter, leaves a gap) everywhere in this unit; `ALPHA` → `BRAVO` is the recorded `overflow` negative. Equal-width tail case: a permutation such as `ALPHA` → `AHPLA` (identical advance).
### Tag gate (ActualText / MCID)
- **Amendment 23:00 (ds2 m87):** `edit-tagged.pdf` keeps `/ActualText` on the StructElem, not in the `BDC` dict (`/Span <</MCID 0>> BDC`; elem 7 0 via `/StructTreeRoot /ParentTree`). Approved: in addition to the inline-dict path below, resolve `MCID` → page `/StructParents` → `/ParentTree` (`/Nums`, `/Kids` ranges) → StructElem; if that elem's `/ActualText` equals the payload, `put("ActualText", newString)` on the elem **inside the same `mutate`** (a journaled dict write; the only write outside the owning stream this unit allows). If it differs → `ambiguous-text-association`. If both an inline `BDC` ActualText and a StructElem ActualText apply → `ambiguous-text-association`. `/Alt` untouched. Undo must restore the elem string (assert it).
- U2 tracks marked content in the walk: `BDC` with an inline dict operand → re-lex the dict's bytes for `/ActualText` (literal or hex string span) and `/MCID`; `BDC` with a name operand → look up `/Properties` in resources. `EMC` pops. Record on each text target: `actualText:{start,end,bytes}|null`, `mcid:number|null`, `ocDepth`.
- If the run's `actualText.bytes === payload bytes` → rewrite that span in the same operation. If an ActualText exists and differs, or the property list is a shared resource, or the run is under **two** ActualText scopes → `ambiguous-text-association`. `MCID` is left as is. No other string in the document is touched.
- **Optional content:** any `BDC` whose operand is `/OC` (or a property list with `/Type /OCG|/OCMD`) → the run is `unsupported-graphics-state` at discovery. Resolving visibility is later; never offer a hidden edit. Update the U1 test expectation if one changes.
### Inline images without `/L` (U1 ceiling, lifted for the unfiltered case)
- If the `BI` operands have no `/F`/`/Filter`: data length = `ceil(W × BPC × comps / 8) × H` with comps from `/CS` (`/G`,`/DeviceGray`→1; `/RGB`,`/DeviceRGB`→3; `/CMYK`,`/DeviceCMYK`→4; `/I`,`/Indexed`→1; `/IM true`→1 bit 1 comp; a named colourspace resource → refuse as today). Skip that many bytes, require whitespace then `EI`. Filtered inline images still refuse the page. Test with `targets-unsupported.pdf` (grok confirms its `BI` is unfiltered; if not, add one).
### Write
- Replace `[operandStart, operandEnd)` (and the ActualText span) in the owning stream element only, via `writeStream` on that element; sibling `/Contents` elements untouched. Inside a Form XObject → impossible here (Form descendants are not candidates in U1).
- After success, `editScanCache` is naturally stale (revision changed). Verify undo restores the exact stream bytes (Gate C infrastructure).
