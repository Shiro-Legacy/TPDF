## Layout / interaction
- Native titlebar uses Electron's real controls (mac hiddenInset optional; native Windows frame). New `#titlebar` and `#document-title` can show document basename and local-only status. No OS-level custom window buttons.
- Top file toolbar: Open, Save, Save a copy primary, Print; New from images and Export reachable (secondary file group / disclosure allowed). Undo/Redo stay visible. Compact Find and page navigation can wrap at 900px.
- Mode buttons (ids FIXED for shared GUI tests): `mode-read`, `mode-annotate`, `mode-organize`, `mode-forms`. Use real `role=radio`, checked state, roving tabindex + arrows for a radiogroup, or native radio controls. Initial Read is safe. New mode changes show the relevant existing context toolbar and inspector; do not mark docs simply by switching.
- Annotate row: current markup-from-search-match (honest labels/tooltips), notes, text box, square/circle/line, ink, stamps, signature image (not certificate signing). Pending note/text/ink tools must cancel on leaving Annotate; native menu/shortcut activation should switch to the appropriate mode before arming it so visual state is truthful. Existing menu operations/smokes keep working.
- Organize row: existing page operations, insert/extract, watermark/header-footer/page labels. Keep all existing IDs.
- Read row: useful current reading actions (navigation/bookmarks/links etc); no fake edit tools. Fill forms selects existing fields inspector; show friendly empty state if this page has none.
- Left sidebar Pages / Bookmarks using tabs. IDs `tab-pages`, `tab-bookmarks`; preserve `thumbs-toggle` as collapse toggle and existing thumbnail keyboard/virtualization behavior/row height contract. Move page operation buttons out of thumb rail into Organize context row.
- Right inspector tabs: Comments, Fields, Links, Text, Layers with IDs `tab-notes`, `tab-fields`, `tab-links`, `tab-text`, `tab-layers`. Single visible panel. Existing sections `notes`, `fields`, `links`, `layers`, extracted text remain. `extracted` lives in new `text-panel`. Existing read-only/empty conditions must not defeat panel switching. Keyboard tabs switch with arrows/Home/End; tab selected state and controlled panels match. Collapse via `inspector-toggle` accessible labelled toggle; keep the single inspector unhidden when a mode needs it.
- Bottom status: real page count/zoom/edit status (no hardcoded Original unchanged once save overwrites). Errors and warnings remain visible in a notice area; no clipping/ellipsis for actionable errors.
- Keep page canvas first among document canvases for existing probes, accurate pointer/text geometry, print CSS, password dialog/form and drop overlay. Beware resize loops, hidden panel state vs data availability, keyboard focus when a panel disappears, page fields auto-refresh after navigation.
