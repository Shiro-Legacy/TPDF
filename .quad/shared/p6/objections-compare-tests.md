## checkedFine
- `from` pre-answer path works for a menu/keystroke op: main.ts:680 (`smoke && insertFromArg`), :1721 (set per drive line and never cleared), renderer pickInsertSource :7165.
- Identical pair → differing 0: nav p0 rendered twice and in fresh sessions at 0.25/1/1.37/1.5/2 gives equal sha256, and the engine render equals a journal-less raw open (lines.out, raw.out).
- hello-vs-nav differing > 0 at every scale (small.out); hello-vs-nav2 1670 ≠ 1590 at scale 1.
- compare-text is callable without a renderer (dispatch is synchronous; the engine test shape is above). The drive STATE waits for the returned promise (`driven`, renderer.ts:1013-1016), so compare work returned from runEditRequest is visible in the next STATE.
- The coverage test regex (tests/p2-shell.test.mjs:164) will force a classification for every new `op:"compare-*"`. No test pins the top-level STATE keys or menu accelerators.

## buildRisks
- `compare` must return a promise that covers render A, compare-render B, the diff and compare-text. `open` must await the compare refresh before its STATE, otherwise steps 3 and 9 read stale or null values.
- Keep B pixels out of A's render cache (key `${page}:${scale}:${revision}` renderer.ts:1944). A key collision makes hello-vs-nav read 0.
- Diff the raw RGBA buffers, never a `getImageData` readback of a scaled canvas.
- `resetDocument` on `open` must not clear the compare state (D1). tests/p2-shell.test.mjs is also edited by debt2 and Bates, so edit it only after a fresh read.
- The pickInsertSource error texts say "insert limit" (renderer.ts:7173-7175); compare needs its own wording or a parameter.
