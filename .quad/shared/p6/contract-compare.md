# Compare — two documents side by side, a text diff from the structured-text lines and a pixel diff from the rasteriser

Drafted 2026-09-24 by fable51 (lean mode, Opus 5.5 subagents, no fixture phase). Line numbers from `maps-compare.md`; re-grep. **Decisions (fable51's, lite mode; lazier alternative named; each built as written):**

- **D1 (second document)** — `session.compare = { doc, name, pageCount } | null` in the SAME session and worker (the clipboard scratch-doc pattern engine.ts:3362; no second worker — the WASM heap budget). Ops: `compare-open { bytes, name }` (unencrypted only, `needsPassword`/encrypted → `encrypted`; ≤ `MAX_PDF_BYTES`), `compare-close`, `compare-render { page, scale }` (the `render` op body on the compare doc: pixels + `lines`). `open`/`close` of the main document leave the slot alone (the human compares a new file against the same reference); `compare-open` closes a previous compare doc first. `OP_PERMISSION`: `compare-open`/`compare-close` `"any"`, `compare-render` `"any"` (the compare doc is view-only; its own `copy` permission gates the text diff: `no-copy-permission` → pixel diff only, said in the UI).
- **D2 (text diff)** — engine op `compare-text { pageA, pageB }`: `parseLines` on both pages (the `render` path's `toStructuredText("preserve-spans")` :1106, without rasterising), then a line-level LCS over normalised `Line.text` (trim, collapse spaces) → `{ same: n, removed: [{text, bbox}], added: [{text, bbox}], moved: 0 }` (bbox in page pt of the side it belongs to). Lazier alternative taken: no word-level diff, no move detection (the `moved` field is 0 and documented as a ceiling).
- **D3 (pixel diff)** — in the renderer: both pages rendered at ONE scale (the current `renderScale`, clamped so both fit `MAX_PIXEL_EDGE`), sizes normalised to the larger canvas; per pixel `|Δr|+|Δg|+|Δb| > 48` counts as different; `{ differing, total, ratio }` and an overlay canvas painting differing pixels red at 60 % over B. `ponytail:` no anti-aliasing tolerance beyond the threshold, no alignment search. Lazier alternative rejected (engine-side diff): the renderer already holds A's pixels in its cache.
- **D4 (view)** — no new UiMode. `#compare-view` (`<section hidden>` inside `#workspace` after `#reader`): `#compare-canvas-a`, `#compare-canvas-b`, `#compare-overlay` toggle (`<input type="checkbox" id="compare-show-diff">`), `#compare-summary` (`role="status"`), `#compare-list` (table of removed/added lines, click a row → scrolls A/B to the line's bbox — a `title` on the row is enough), `#compare-page-b` (number input, defaults to A's page), `#compare-close`. Entering compare hides `#reader` and follows A's current page; leaving shows it again. Lazier alternative (a dialog) rejected: side-by-side needs the width.
- **D5 (entry)** — View menu "Compare with…" `Alt+CmdOrCtrl+K` → `edit-request {op:"compare"}`; renderer `contents === null` → `pickInsertSource()` (the existing `insert-source` channel, `from` pre-answer, main.ts:677-702) → `compare-open`; drive `compare { from: path }` or `compare {close:true}` or `compare {page:n}` / `compare {pageB:n}`. `OP_MODE["compare"]` = none.

## 0. Ground rules

## 1. Engine (`src/renderer/engine.ts`, `engine-core.ts`, `worker.ts` op list if any)
1.1 Types per D1/D2; `Session.compare` (:760 neighbourhood) with the `:796`-style comment; `closeSession`/worker teardown destroys it.
1.2 `compareText()` LCS: O(n·m) on lines (≤ a few hundred per page); the diff for two identical pages is `{same: n, removed: [], added: []}`; for A=`hello.pdf` p0 vs B=`nav.pdf` p0 it lists every line on both sides.
1.3 Tests (`tests/p6-compare.test.mjs`, engine half): (a) `compare-open` nav.pdf, `compare-render` p0 at 1 gives pixelWidth/Height equal to the main render of the same page; `compare-text` p0 vs p0 of the same file opened as main → same = lines count, empty lists; (b) A = hello.pdf vs B = nav.pdf → removed ⊇ hello's line, added ⊇ nav p0's lines, bboxes 4-arrays inside the page; (c) `encrypted.pdf` → `encrypted`, `encrypted-noprint.pdf`? (copy permission) → `compare-text` refuses `no-copy-permission` while `compare-render` works — check which fixture lacks copy (grep tests/p5 for 'copy'); (d) `open` of another main doc keeps `session.compare`; `compare-close` empties it; `compare-render` after close → `no-compare-document`; (e) the main doc's revision/dirty/journal are unchanged by every compare op; (f) `close` of the main document does NOT close the compare slot (D1) — pin it.

## 2. Renderer (`renderer.ts`, `index.html`, `styles.css`)
2.1 View per D4; CSS: two canvases side by side (`display:grid; grid-template-columns: 1fr 1fr`), overlay absolutely over B. Accessible names for every control (p2-shell rule); REQUIRED_IDS additions if the list enumerates views.
2.2 `openCompare(bytes, name)`, `closeCompare()`, `refreshCompare()`: on page change of A while compare is open, B follows to `pageB` (defaults to A's page, clamped to B's pageCount; the human can set `#compare-page-b`); render A from the cache (same key scheme) and B via `compare-render`; compute D3; request `compare-text`; fill `#compare-summary` "Page 3 vs 3: 12 lines same, 2 removed, 1 added; 3.4 % of pixels differ"; announce it.
2.3 STATE `compare: { open: boolean, name: string|null, pageCount: number|null, pageA: number, pageB: number, text: { same, removed: number, added: number, refused?: string } | null, pixels: { differing, total, ratio: number(4 dp) } | null, showDiff: boolean }`.
2.4 Help item: "Compare with… (⌥⌘K) opens a second PDF beside the current one: the list shows lines that appear only on the left or only on the right (moved lines count as removed and added), and the red overlay marks pixels that differ at the current zoom. Nothing is written." Pinned.
