## checkedFine
- Every refresh is mode-blind data plus a mode-gated paint. `refreshNotes` (:5093), `refreshFields` (:5134) and `refreshLinks` (:5675) fetch in any mode. `paintHits` paints fields only in read/annotate/forms (:2546), links in read/annotate (:2551), objects and runs in edit (:2604-2622) and marks in redact (:2626). A paste refresh in any mode therefore never paints a layer that the mode hides. `setMode('edit')` rescans (:4853), so objects pasted in another mode appear when the user switches.
- The inline editors for runs (:3394), fields (:3368), add-text (:3465) and links (:6176) are all `.inline-editor` children of `#hit-layer`. `directActive` is set while any of them is open, so "not `.inline-editor` and `directActive` null" covers paste while a run editor is open (native paste into the input) in every mode. The link form's target input (#link-target, :372) and the Fields panel controls are outside `#hit-layer`, and so is the Inspector.
- tests/p3-drive.test.mjs:93-97 deep-equals only object-edit.jsonl's single edits. p6-drive6/7 `brief` (p6-drive6:79, p6-drive7:87) records `edited` without deep-equalling a paste. `direct.clipboard` gaining four `kinds` keys is safe under subset `expect` (template line 35 pins only image and form).
- Help: `helpRows()` stays 11. The direct-editing cell is index.html:559 and its ceilings `<ul>` has no id (:569). `#help-ceilings` is the Form designer list (:571).

## buildRisks
- The R10-3 predicate is the riskiest line in the unit: it decides whether a real-mouse ⌘V works after mode or page changes, and the drive cannot see focus there. Pin it as a pure function with activeElement fixtures (radio, thumb button, `#page`, `.inline-editor`, dialog input) and a collapsed or non-collapsed selection flag.
- Selecting after paste has to wait for `applyEdit` and the forced scan. A parallel `refreshLinks` repaint (:5697) can run `restoreDirectFocus` against the old selection. Set `directSelection` only after both awaits, then repaint once.
- A mixed paste in Fill forms writes objects, runs, links and marks that stay invisible there. One ⌘Z removes them all. The announcement (R10-8) is the only cue, so keep it exact and pinned.
- Fixtures 9/9 OK after the probe (it opened no fixture). The lock was released, and no Electron with `--drive=` was touched.
