- `Object.keys` counts an explicit `box: undefined`. The renderer never sends one (renderer.ts:2926), but an agent's JSON may omit it. Do not treat undefined values specially.
- `ClipItem` text gains `tr: 0|1|2` (engine.ts:812). Build it from `record.renderMode`, never a default 0, or the E-4 assert catches it.
