# P6 U8 — duplicate text on the page stays editable (added, pasted and typed runs each keep their own target)

Drafted 2026-09-24 by fable51 after U7 acceptance (progress.md §6 "P6 U7"), from the human's report "text I add is no longer editable once I click away". Lean mode, Opus 5.5 subagents, no fixture phase. Small unit: one engine change, its tests, one drive, Help wording. **Decisions for the human (D1–D2); each is built as written unless changed:**

- **D1 — scope of the relaxation:** a run in direct page content (`depth === 0`) whose structured-text match at its own origin is unique becomes a candidate even when the same text appears elsewhere on the page as a whole line. Runs inside a Form XObject (`depth > 0`) keep the P3 rule (a Form painted twice shows one operator in two places, so an edit would change both). Overprinted duplicates (two operators at one origin, `near.length > 1`) stay `ambiguous-text-association`.
- **D2 — Help:** the U7 ceiling sentence "A pasted run whose text already appears as a whole line on the page cannot be edited until one of them changes." is removed; the reason text for `ambiguous-text-association` stays for Forms and overprints. `tests/p2-shell.test.mjs:205` pins Help verbatim, so it changes with it.
