                What can be edited

          Existing text
          Click a line or a paragraph and type. Longer text pushes the rest of the line along while there is room. In a font the file includes only in part, the letters it already has on the page can be typed.
          The font is incomplete: only letters it already has on this page can be typed. This font's letters cannot be read, so the text cannot be edited. This text is drawn in a way the editor does not support yet. Decorative or vertical text cannot be edited. Right-to-left or joined-script text cannot be edited yet. The same text is drawn twice here, so it cannot be edited. Text that would grow past the free space on its line. Pages printed to PDF (one letter at a time, as macOS "Save as PDF" makes them) are edited line by line, with only the letters each line's font already has on that page; a change of font inside a line splits it into separate lines, and such a line cannot be copied, cut or duplicated.
        
                
        
                
          Add text
          Choose Add text in Edit text, click the page and type; several lines are fine. New text uses a standard font: Helvetica, Times or Courier.
          Letters outside Western European alphabets, rotated pages, your own font files, re-flowing paragraphs.
        
                
        
                
          Shared content
          Content a page shares with other pages gets a private copy for that page first, so the other pages keep the original.
          This content is shared with other places and cannot be edited here yet: content nested more than one level deep, and find and replace across shared content.
        
                
        
                
          Images and objects
          Replace a picture with a PNG or JPEG; move, resize, rotate, flip, crop or delete pictures and drawn objects.
          A picture with a mask or layer cannot be replaced yet. Hidden, clipped or unusually drawn text cannot be edited. Skewed, nested or fully clipped content cannot be edited yet. This object is used in several places: edit one placement at a time. This kind of object cannot be edited. Pages that are rotated or scaled.
        
                
        
                
          Find and replace
          Exact text, matching capital letters, on this page or in the selected line, with a preview where you tick what changes; one Undo takes it all back.
          Patterns or wildcards, ignoring capital letters, matches that run across lines or pages, shared content.
        
                
        
                
          Form designer
          create text, checkbox, dropdown and radio fields; rename, move and resize them; max length, multiline, options, accessible label, read-only, required and default value; delete; fill in the same session
          Adobe dynamic forms or fields with scripts, fields nested inside other fields, filling a field marked read-only (the designer can still clear it), typing a value into a signature field, list boxes, push buttons, drag placement (except signature fields), reset to default, very large forms (over 4096 fields and parts)
        
                
        
                
          Certificate signing
          Sign with a certificate file (.p12, .pfx or .pem); a visible or an invisible signature; a document can be signed more than once; certify it to allow only form filling and further signatures afterwards; click an empty signature field on the page to sign it there, or draw one with "Draw signature field" in Fill forms; after signing, the signed copy opens; signed fields show a badge — "Signed" until Verify runs, then Valid, Invalid or Unsupported
          Password-protected documents, and documents certified to allow no changes, cannot be signed; a certified document accepts only an invisible signature or one in an existing empty field, and only when its certification allows form filling; the signature's look is this app's text and replaces the field's own; no field locking, seed values or per-field permissions; badges do not re-check on their own; only RSA keys of 2048 bits or more with SHA-256 (no ECDSA); no trusted timestamp or revocation data is added; the certificate chain is embedded as found; visible text is clipped to its box; Keychain identities must be exported to a .p12 file first; the app lets go of the unlocked private key right after signing, on Cancel or after 5 minutes unused, but cannot erase it or the certificate password from memory, so copies of both may stay in the app's memory until it quits
        
                
        
                
          Signature verification
          Verify checks that each signature is intact, what part of the file it covers, and whether its signer leads to a certificate you trust
          Trust is imported only; any program running as you can add to the trusted list; no built-in trusted certificates, revocation checks, timestamps or long-term validation; changes made after signing are not analysed; older SHA-1 signatures are unsupported; certificates in the chain must be valid at signing time; no key usage or extended key usage checks; encrypted signed documents cannot be verified in this version; documents above 50 MB are not verified
        
                
        
                
          Redaction
          mark an area or every text match, preview shared graphics and sanitization, then apply into a new file; marking alone is not redacting
          shared graphics without a mark, pages too complex to scan, images over 40 million pixels, signed or certified files; Redaction is limited to documents up to 12 MiB in this version; raster text needs an area mark; inline alternate text is removed only when a search mark's post-check proves it is gone, not by a rect mark; no OCR, custom colours or page-range batch
        
                
        
                
          Direct editing
          Fill existing fields; in Fill forms choose Add text box, then click the page to type a text box (drag it to move, arrows nudge it, Delete removes it; not on rotated pages), and "Sign…" ▸ "Add my signature" (or Cmd/Ctrl+Shift+J) places your saved signature where you click (drag to move, handles or +/- to resize, Delete removes it; make it once in "Draw signature…" by drawing with a pointer or with "Use an image…" (one PNG or JPEG, the keyboard-only way; its background is not made transparent); one signature is kept, on this Mac only, where any program running as you can read the file; it is a picture, not a certificate signature; not on rotated pages), and the first Save of a filled form asks whether to save over it or as a new file; drag and resize fields and supported text runs; edit text paragraphs; ⌥-click a run for single-run editing; ⌥-arrow nudges focused fields; open editors stay in place on zoom; images and forms can be dragged, resized (a corner keeps the picture's proportions, Shift frees it), deleted (Delete) and replaced (Enter or double-click) on the page in Edit text; choose Add text in Edit text and click empty space to add text there (Enter is a new line, ⌘Enter commits; Esc stops the tool); redaction marks can be dragged, resized and deleted on the page in Redact mode, and dragging on empty page space in Redact mode marks an area; links are followed by clicking them in Read mode, and in Annotate mode moved, resized, retargeted (Enter) and deleted (Delete) on the page; "Draw link" (Links tab) draws a new one; Tab follows the page's tab order (rows, columns, or the order the file lists its fields); plain arrows nudge a focused field, object, mark or link by 1 pt (Shift 10 pt); Edit text outlines every editable object and text block ("Outline objects" toggle); Shift-click selects several images or forms (drag, arrows and Delete then act on all of them, moving as one block); ⌥-drag duplicates the selection; right-click, Control-click or Shift+F10 on an object opens the object menu (Replace, Duplicate, rotate, flip, Crop, Delete); the menu and the Inspector also rotate an image or form in 90° steps, flip it, and crop an image or form (drag the handles inside the picture; Enter or Escape ends cropping); a multi-selection shows one frame with handles that resize it as a block; dragging snaps edges and centres to other objects and the page within 4 pt (hold ⌘ to drag freely); a form that surrounds other objects is picked by its border so clicks inside reach what it surrounds; Cut, Copy and Paste work on any selection: images, forms, text runs, fields, links and redaction marks (⌘X/⌘C/⌘V or the menu; right-click empty space to paste there); Shift-click adds a text run, field, link or mark to a selection (Shift-click a field or run to select it alone), then drag, arrows or Delete act on all of them
          Single-run width follows its text; paragraphs must be upright, left-aligned, uniform-leading, single-font base-14/WinAnsi; no hyphenation or justification; page checks for resized rotated runs are approximate; nested images stay in the panel (replace only); an object covering 90 % or more of the page is panel-only; rotation in 90° steps and flips only; a crop is one rectangle inside the picture; a moved search mark becomes an area mark; added text is one base-14 font per run, WinAnsi only, on unrotated pages only; links are followed in Read and edited in Annotate only, with no border, colour or highlight editing, and page targets are whole-page fits; a multi-selection moves, resizes, rotates, flips and deletes as a block but is not cropped; duplicates share the original's picture data; guides snap to images, forms and the page edges only, within 4 pt of the page
        
                
        
                
          Always
          Saving rewrites the whole file and drops parts nothing uses; it keeps the file's current password protection; every action is one Undo step, and an action that is not possible leaves the document untouched
          Signed, certified or locked files, a document whose settings forbid the change, and any script or action written into the file (never run)
        
                
                      
    
                
    
                Direct editing ceilings
                
    
                • Tab follows the page's tab order: by rows (the default) in reading order, by columns top to bottom, or in the order the file lists its fields; it continues onto the next page with fields and wraps at the end.
                • Links are followed in Read mode and edited in Annotate mode only; Forms, Edit text and Redact modes paint no link targets. A link fully under a field is reachable only from the Links tab, and a link over text blocks text selection there. No border, colour or highlight-mode editing; page targets are whole-page fits (no named destinations, no zoom); only http:, https: and mailto: web links are opened or written. A link under an open inline editor is not draggable until the editor closes.
                • Text, combo and list fields move with ⌥-arrows only (they open their editor on focus), or with plain arrows when two or more are selected; plain arrows nudge a checkbox, radio or empty signature field in Forms mode only (in Read and Annotate they scroll), and on a radio plain ↑/↓ nudge the widget while ←/→ move the selection.
                • Paragraphs require upright, left-aligned, uniform-leading text and one base-14/WinAnsi font; no hyphenation or justification. Single-run width follows its text.
                • Page checks for resized rotated runs are approximate.
                • Gestures use page-point bounds and follow page rotation; content edits remain limited to proven targets.
                • Combos with the Edit flag accept typed values.
                • Moving one of several search marks for the same text leaves that occurrence visible, so Apply refuses until it is marked again.
                • ⌥⌘↑ and ⌥⌘↓ move the page, so an object's or mark's height is resized by dragging; ⌥⌘← and ⌥⌘→ change its width.
                • An object covering 90 % or more of the page has no on-page target (use the Text panel); a form that surrounds other objects takes clicks on its border only, and a click inside reaches what it surrounds.
                • Text placed exactly on top of the same text cannot be edited; text inside a form drawn more than once has no on-page target (edit it from the Text panel, this placement only).
                • A selection stays on one page and in one mode: images, forms and single text runs in Edit text, fields in Fill forms, links in Annotate, marks in Redact; a duplicate is placed by the drop point (or 10 pt right and down from the menu) and stays inside the page. Arrow keys do not move the crop window; drag its handles.
                • The clipboard belongs to this window and is not the system clipboard.
                • Pasted text keeps its font, size and whether it is filled, stroked or both, but is black with a 1 pt stroke; kerning and text rise are dropped.
                • A signature field, a scripted field and a run inside a Form cannot be copied.
                • Text runs cannot be cut or deleted; Cut copies them and removes the rest.
                • A link to a page the target document does not have is skipped when pasting.
                • A run that continues a line cannot be copied.
                • Paragraphs cannot be selected, copied or cut.
                • Once a picture's full box leaves the page, its crop cannot be removed until it is moved back inside.
                • Clipping set up before an object starts drawing is not seen, so that object's box is its full drawn rectangle.
                
    
                Form designer ceilings
                
    
                  
      
                • No reset to default; setting a default value is all that is offered.
                  • 
      
                • Top-level fields only: a field inside a hierarchy cannot be renamed, moved or deleted.
                  • 
      
                • One Helvetica 12 point appearance for every authored field.
                  • 
      
                • Field flags are read-only and required; no hidden, no-export, comb or password flag.
                  • 
      
                • A radio group carries one accessible label; the kids have none of their own.
                  • 
      
                • A checkbox on-state is the export name Yes.
                  • 
      
                • No list boxes or push buttons; drag placement exists only for signature fields (other kinds are typed in page points).
                  • 
    
                
    
                Headers, footers and Bates numbers
                • Bates numbering: put {bates} in a header or footer; the count continues across the documents you open in this window and undo does not move it back — set the start in the dialog.
                • Batch (⌥⌘B) applies one header, footer or watermark to every PDF in a folder; results go to a pdf4all-out folder beside them with a report.txt, and {bates} keeps counting from file to file. Encrypted or read-only files are listed as failed and skipped.
                
    
                Compare
                • Compare with… (⌥⌘K) opens a second PDF beside the current one: the list shows lines that appear only on the left or only on the right (a moved line counts as removed and added), and the red overlay marks pixels that differ at 72 dpi. Nothing is written.
                
    
                New document
                • File ▸ New… (⌘N) opens a blank one-page Letter document named Untitled.pdf (agents can ask for A4 or a custom size in points); Save (⌘S) asks where to keep it.
