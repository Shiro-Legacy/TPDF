                What can be edited
                
    
                
      
        
                AreaSupportedRefused
                
                      
      
        
                
          Existing text
          single show-text runs in base-14, simple-encoding and full embedded or Identity-H CID fonts with a proven ToUnicode map; kerned TJ runs are supported; growth within free space shifts following text; inline text and StructElem ActualText are rewritten together
          Quote operators are not editable, Type 3 / vertical text is read-only, Right-to-left or shaped text is read-only, Subset font: new characters cannot be drawn, Encoding not supported, Appears more than once; cannot be told apart, growth past the free-space limit, tagged content in a Form inside a Form. Symbolic fonts with no encoding (LibreOffice exports and similar) are editable the same way: only characters already drawn with that font on the page. Print-to-PDF pages (macOS "Save as PDF", one glyph at a time) are edited line by line, with only the characters the line's font already has on that page; a font change inside a line splits it into separate lines, an edited line is redrawn unclipped, and such a line cannot be copied, cut or duplicated.
        
                
        
                
          Add text
          Add unembedded base-14 text in WinAnsi, including multiple lines.
          Unsupported characters, rotated pages, no font embedding or reflow.
        
                
        
                
          Shared content
          copy-on-write of one placement: inherited resources, a shared Contents array, a Form invocation at depth 1
          Shared or nested content (not yet editable), a Form inside a Form, tagged content inside a Form, batch replace over a shared Form
        
                
        
                
          Images and objects
          replace an Image XObject with a local PNG or JPEG, and move, resize or delete a simple placement
          Image with a mask or layer (not yet replaceable), Hidden, clipped or unusual drawing state, Skewed, nested or fully clipped placement (not yet editable), Shared placement: edit it individually, Object type not supported, pages with a rotation or a user unit
        
                
        
                
          Find and replace
          literal, case-sensitive text on the current page or in the selected run, with a preview, an explicit tick, one undo step and a bounded result list
          regular expressions, case folding, matches that cross a run or a page, shared Forms in a batch
        
                
        
                
          Form designer
          create text, checkbox, dropdown and radio fields; rename, move and resize them; max length, multiline, options, accessible label, read-only, required and default value; delete; fill in the same session
          XFA or scripted fields, fields inside a hierarchy, filling a field marked read-only (the designer can still clear it), typing a value into a signature field, list boxes, push buttons, drag placement (except signature fields), reset to default, forms over 4096 nodes
        
                
        
                
          Certificate signing
          RSA/SHA-256 PKCS#12, PFX or PEM; visible text-only signature or invisible signature; second signatures use incremental updates; certify to allow form filling and further signatures; click an empty signature field on the page to sign it in place (any mode that shows fields); draw one with "Draw signature field" in Forms mode or add kind "signature" in the designer; signed fields show a badge — "Signed" until Verify runs, then Valid, Invalid or Unsupported
          Encrypted documents and certified P=1 documents cannot be changed; a certified document accepts only an invisible signature or a signature in an existing empty field, and only when the certification permits form filling; the signed appearance is this app's text appearance and replaces the field's own; no /Lock, seed values or per-field permissions; badges do not re-verify on their own; RSA/SHA-256 only (no ECDSA or PSS), 2048-bit minimum; no timestamp, long-term validation, OCSP or CRL; chains are embedded as found, not built; visible text is clipped to its box; Keychain identities must be exported to .p12; JS strings and KeyObject memory cannot be wiped
        
                
        
                
          Signature verification
          Verify supported detached CMS signatures, coverage, and chains to certificates you trust
          Trust is imported only; any program running as you can add to the trusted list; no system roots, revocation, timestamps, LTV or DocMDP change analysis; post-signature changes are unverified; SHA-1 PKCS#7 and X.509 RSA-SHA1 are unsupported; certificates in the chain must be valid at signing time; no key usage or extended key usage checks; encrypted signed documents cannot be verified in this version; documents above 50 MiB are not verified
        
                
        
                
          Redaction
          choose Redact and drag a box over anything you want removed (or "Find text to redact…", or right-click a page for "Redact whole page"); the boxes are listed in the Redactions panel; "Redact N areas…" removes everything inside them into a new file, which then opens in the window; signed files are redacted into an unsigned copy; artwork that can't be cut precisely turns its page into an image, after asking; drawing boxes alone is not redacting
          pages too complex to scan, images over 40 million pixels; Redaction works on files up to 12.5 MB in this version; text inside pictures needs a box drawn over it (Find text does not see it); no OCR, custom colours or page-range batch
        
                
        
                
          Direct editing
          Fill existing fields; in Fill forms click empty page space to type a text box (drag it to move, arrows nudge it, Delete removes it; not on rotated pages), and "Sign" (or Annotate's "Sign…", Cmd/Ctrl+Shift+J) places your saved signature where you click (drag to move, handles or +/- to resize, Delete removes it; make it once in "Draw signature…" by drawing with a pointer or with "Use an image…" (one PNG or JPEG, the keyboard-only way; its background is not made transparent); one signature is kept, on this Mac only, where any program running as you can read the file; it is a picture, not a certificate signature; not on rotated pages), and Save on a filled document asks for a copy named "(filled)"; drag and resize fields and supported text runs; edit text paragraphs; ⌥-click a run for single-run editing; ⌥-arrow nudges focused fields; open editors stay in place on zoom; images and forms can be dragged, resized (a corner keeps the picture's proportions, Shift frees it), deleted (Delete) and replaced (Enter or double-click) on the page in Edit text; click empty space in Edit text to add text there (Enter is a new line, ⌘Enter commits); redaction boxes can be dragged, resized and deleted on the page in Redact, and dragging on empty page space in Redact draws a box; links are followed by clicking them in Read mode, and in Annotate mode moved, resized, retargeted (Enter) and deleted (Delete) on the page; "Draw link" (Links tab) draws a new one; Tab follows the page's /Tabs order (rows, columns, structure or annotation order); plain arrows nudge a focused field, object, mark or link by 1 pt (Shift 10 pt); Edit text outlines every editable object and text block ("Outline objects" toggle); Shift-click selects several images or forms (drag, arrows and Delete then act on all of them, moving as one block); ⌥-drag duplicates the selection; right-click, Control-click or Shift+F10 on an object opens the object menu (Replace, Duplicate, rotate, flip, Crop, Delete); the menu and the Inspector also rotate an image or form in 90° steps, flip it, and crop an image or form (drag the handles inside the picture; Enter or Escape ends cropping); a multi-selection shows one frame with handles that resize it as a block; dragging snaps edges and centres to other objects and the page within 4 pt (hold ⌘ to drag freely); a form that surrounds other objects is picked by its border so clicks inside reach what it surrounds; Cut, Copy and Paste work on any selection: images, forms, text runs, fields, links and redaction marks (⌘X/⌘C/⌘V or the menu; right-click empty space to paste there); Shift-click adds a text run, field, link or mark to a selection (Shift-click a field or run to select it alone), then drag, arrows or Delete act on all of them
          Single-run width follows its text; paragraphs must be upright, left-aligned, uniform-leading, single-font base-14/WinAnsi; no hyphenation or justification; page checks for resized rotated runs are approximate; nested images stay in the panel (replace only); an object covering 90 % or more of the page is panel-only; rotation in 90° steps and flips only; a crop is one rectangle inside the picture; a moved search mark becomes an area mark; added text is one base-14 font per run, WinAnsi only, on unrotated pages only; links are followed in Read and edited in Annotate only, with no border, colour or highlight editing, and page targets are whole-page fits; a multi-selection moves, resizes, rotates, flips and deletes as a block but is not cropped; duplicates share the original's picture data; guides snap to images, forms and the page edges only, within 4 pt of the page
        
                
        
                
          Always
          saving as a full rewrite (never incremental) with orphan objects collected; the current encryption; and one undo step per action, with a refused action leaving the document untouched
          signed, certified or locked files, a document whose permissions forbid the change, and any JavaScript or action written into the file
        
                
                      
    
                
    
                Direct editing ceilings
                
    
                • Tab follows the page's /Tabs order: rows (or no /Tabs) use the visible reading order, columns go top to bottom column by column, structure order falls back to reading order when the page has no reachable structure, and annotation (A) and widget (W) order both follow the page's annotation order; Tab continues onto the next page with fields and wraps at the end. The list-box top index (/TI) is not changed.
                • Links are followed in Read mode and edited in Annotate mode only; Forms, Edit text and Redact modes paint no link targets. A link fully under a field is reachable only from the Links tab, and a link over text blocks text selection there. No border, colour or highlight-mode editing; page targets are whole-page fits (no named destinations, no zoom); only http:, https: and mailto: web links are opened or written. A link under an open inline editor is not draggable until the editor closes.
                • Text, combo and list fields move with ⌥-arrows only (they open their editor on focus), or with plain arrows when two or more are selected; plain arrows nudge a checkbox, radio or empty signature field in Forms mode only (in Read and Annotate they scroll), and on a radio plain ↑/↓ nudge the widget while ←/→ move the selection.
                • Paragraphs require upright, left-aligned, uniform-leading text and one base-14/WinAnsi font; no hyphenation or justification. Single-run width follows its text.
                • Page checks for resized rotated runs are approximate.
                • Gestures use page-point bounds and follow page rotation; content edits remain limited to proven targets.
                • Combos with the Edit flag accept typed values.
                • Moving one of several search marks for the same text leaves that occurrence visible, so Apply refuses until it is marked again.
                • ⌥⌘↑ and ⌥⌘↓ move the page, so an object's or mark's height is resized by dragging; ⌥⌘← and ⌥⌘→ change its width.
                • An object covering 90 % or more of the page has no on-page target (use the Text panel); a form that surrounds other objects takes clicks on its border only, and a click inside reaches what it surrounds.
                • Text placed exactly on top of the same text cannot be edited; text inside a form drawn more than once has no on-page target (edit it from the Text panel, this placement only).
                • A selection stays on one page and in one mode: images, forms and single text runs in Edit text, fields in Fill forms, links in Annotate, marks in Redact; a duplicate is placed by the drop point (or 10 pt right and down from the menu) and stays inside the page. Arrow keys do not move the crop window; drag its handles.
                • The clipboard belongs to this window and is not the system clipboard.
                • Pasted text keeps its font, size and whether it is filled, stroked or both, but is black with a 1 pt stroke; kerning and text rise are dropped.
                • A signature field, a scripted field and a run inside a Form cannot be copied.
                • Text runs cannot be cut or deleted; Cut copies them and removes the rest.
                • A link to a page the target document does not have is skipped when pasting.
                • A run that continues a line cannot be copied.
                • Paragraphs cannot be selected, copied or cut.
                • Once a picture's full box leaves the page, its crop cannot be removed until it is moved back inside.
                • A clip set before an object's own q…Q block is not seen, so that object's box is its full drawn rectangle.
                
    
                Form designer ceilings
                
    
                  
      
                • No reset to default; setting a default value is all that is offered.
                  • 
      
                • Top-level fields only: a field inside a hierarchy cannot be renamed, moved or deleted.
                  • 
      
                • One Helvetica 12 point appearance for every authored field.
                  • 
      
                • Field flags are read-only and required; no hidden, no-export, comb or password flag.
                  • 
      
                • A radio group carries one accessible label; the kids have none of their own.
                  • 
      
                • A checkbox on-state is the export name Yes.
                  • 
      
                • No list boxes or push buttons; drag placement exists only for signature fields (other kinds are typed in page points).
                  • 
    
                
    
                Headers, footers and Bates numbers
                • Bates numbering: put {bates} in a header or footer; the count continues across the documents you open in this window and undo does not move it back — set the start in the dialog.
                • Batch (⌥⌘B) applies one header, footer or watermark to every PDF in a folder; results go to a pdf4all-out folder beside them with a report.txt, and {bates} keeps counting from file to file. Encrypted or read-only files are listed as failed and skipped.
                
    
                Compare
                • Compare with… (⌥⌘K) opens a second PDF beside the current one: the list shows lines that appear only on the left or only on the right (a moved line counts as removed and added), and the red overlay marks pixels that differ at 72 dpi. Nothing is written.
                
    
                New document
                • File ▸ New… (⌘N) opens a blank one-page Letter document named Untitled.pdf (agents can ask for A4 or a custom size in points); Save (⌘S) asks where to keep it.
