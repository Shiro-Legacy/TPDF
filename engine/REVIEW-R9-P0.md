# Independent review: bounded path/state display lists

Reviewed `src/path.rs`, its interaction with validated content operations and tagged geometry, and `src/cli_path.rs`. No blocking production issue found in the declared P0 subset.

The independent Python state/event model in `tools/differential-path.py` was first checked against native MuPDF without invoking Rust: 110 cases and 1,939 events passed. The complete three-way comparison subsequently passed 310 cases and 5,835 events, recorded in `reference/path-differential-p0.json`, with unchanged executable hashes. It covers noncommuting transforms, shear/reflection/singular transforms, signed rectangles, v/y expansion, repeated moves/close, degenerate retained segments, style/color save and restore, current paths across q/Q, pending clips across q/Q, last pending clip rule, fill then stroke under the old clip, clipping-only paths, and nested clip restoration.

Twenty strict CLI inputs refuse with nonzero status and no stdout, including unmatched graphics state, unfinished paths/clips, missing current points, mixed path transforms, unsupported text/resources/inline images/compatibility operations, colors outside P0, and inexact integer conversion. A valid painted prefix followed by unsupported text also refuses without partial output.

The test-only `tools/mupdf-path-oracle.c` executes standalone content through `pdf_process_glyph` with an identity CTM, empty resource dictionary and unbounded initial clip. It records path/device callbacks immediately into a capped temporary output file; publication happens only after processing succeeds without native diagnostics. Lexical preflight admits only the P0 operator/number/dash-array subset, preventing omitted unsupported resource callbacks. Caps include 4 MiB input, 128 MiB native allocation, 64 MiB trace, one million tokens/commands, 300,000 events and CPU/wall deadlines. `tools/build-path-reference.sh` reuses pinned static libraries. Explicit Q pops are recorded; only the run processor's final cleanup pops are excluded.

Native representation differences remain explicit. MuPDF collapses consecutive moves and all-equal cubics, so only the native comparison normalizes those cases; Rust still retains original semantic commands. Zero-length lines and zero-size rectangles are preserved. MuPDF emits four empty paint callbacks for `S f B`, while the chosen strict P0 API returns none; this separate expected difference is verified in the report. Native f32 comparisons use absolute 1e-5 and relative 2e-6 tolerances; the independent Rust model uses 1e-13.

Four additional tests in `tests/review_path.rs` pass, along with targeted Clippy/rustfmt. They verify 10,000 discarded paths reuse capacity while cumulative command work remains charged; fill/stroke/clip share one path and clip branches restore exact ancestry; initial Empty and zero-area Rectangle clips retain their distinct supplied forms; and an overflowing transformed cubic control point fails even when endpoints remain finite. Clip nodes and arena IDs are flat, earlier-parent indices avoid recursive destruction, and builder errors are sticky. All arenas, discarded construction work, operations and dash work have explicit limits. These checks do not claim rendering, clipping intersection, stroke expansion, font execution or pixel equivalence.

## Deterministic mutation smoke follow-up

`tools/mutation-smoke.py` completed 1,600 cases (400 each for `--document`, `--fonts`, `--content`, and `--path`) with seed 2026100309. Input is capped at 16 KiB and each subprocess at two seconds. Document/font mutations include rebuilt valid xref tables and stream lengths around corrupted dictionary, CMap, resource and content payloads, allowing mutations to reach the new layers rather than all stopping at file offsets. All baseline cases passed first. No panic, signal, timeout, non-atomic error output or malformed successful JSON was observed; the binary hash remained unchanged. The slowest case took 0.004144 seconds. Full reproducible input hashes and outcomes are recorded in `reference/mutation-smoke-r9.json`. Acceptance of mutated data is not treated as semantic correctness or native parity, and this bounded smoke test is not exhaustive fuzzing.
