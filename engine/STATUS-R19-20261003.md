## Latest capability

PageRasterSession renders owned G1 page glyph programs into opaque RGBA images.
The new safe Rust scan converter has checked rational intersections, metered heap
sorting, half-open sample coverage and explicit cumulative resource limits. It
introduces no new runtime dependency and works without the optional raster feature.
Existing R0 tiny-skia rendering remains separate and unchanged.

Device-space quadratic/cubic flattening has explicit node/depth/edge limits,
1/64-pixel finite-chord flatness and1/256-pixel quantization. Fixed4x4 binary
samples compose in mixed path/text order before a single integer box resolve.
Binary clip masks intersect with AND, so repeated clipping is idempotent. The
initial page boundary remains unsnapped. Positive uniform scale+translation
must preserve page extent precision. Unsupported suffixes publish no image.

Supported paints are opaque Gray/RGB filled paths and unhinted G1 TrueType Tr0
outlines; Tr3 is invisible. Strokes, CMYK, broader fonts, images/Forms, transparency
and other upstream unsupported content still refuse. This is a filled-page subset,
not complete PDF rendering, hinted-native pixel parity or the application rewrite.

`--page-render=N@DPI` outputs atomic P6 PPM for one-based page N. The original
16MiB input and64MiB CLI output limits remain. Existing G1 inspection modes remain.
