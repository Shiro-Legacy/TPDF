## Latest capability

The explicit AllowPinnedBase14 outline policy renders exact Helvetica and
Times-Roman declarations with licensed, pinned URW canonical CFF outline data.
Both policies remain independent: declared PDF widths control advances; explicit
Encoding/Differences select outlines; ToUnicode controls extraction independently.
Malformed embedded programs never fall back. EmbeddedOnly remains the API default.
The two compiled assets add no native/runtime CFF decoder or new library dependency.

The tables contain1,308 glyph records and30,626 commands. Safe Rust performs exact
name lookup, typed source binding, bounded caching and page placement. Cubic glyph
outlines feed the existing R19 renderer. Runtime maps, every lookup/occurrence and
failed request retain cumulative accounting; static data is a separate fixed
partition. TrueType metadata remains confined to its typed source branch.

`--builtin-outlines=Helvetica|Times-Roman` emits canonical assets without an input
PDF. `--page-outlines[=N]` enables the combined policy; legacy `--page-glyph=N` and
`--page-glyphs` retain embedded-only output. `--page-render=N@DPI` explicitly opts
into both pinned metrics and outlines and emits atomic P6 PPM. Input/output caps
remain16MiB/64MiB. The renderer remains opaque Gray/RGB, unhinted filled geometry,
fixed4x4 samples, bounded curve approximation and binary intersected clipping.
