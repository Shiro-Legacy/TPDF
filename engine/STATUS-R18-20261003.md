## Latest capability

PageGlyphSession joins document-bound PP1 page traces to G0 source-byte/GID maps
and O0 simple unhinted outlines. It retains event order, operation/source provenance,
font/program identity, Unicode, text state, colors and clipping. Raw outlines are
shared immutably through Arc; page-space commands are owned by each result.

A validated hhea/hmtx reader supplies the drawing-origin shift lsb-header.xMin.
Coordinates normalize by unitsPerEm and use the existing text/page matrix once.
PDF Widths control advance independently of font-program advances. Repeated
pages reuse cache entries; failed loads/opens/decodes/transforms remain bounded.
Metrics, lookup searches and full arena/handle requests have explicit ledgers.

`--page-glyph=N` emits one-based page N atomically. `--page-glyphs` classifies all
pages in one cumulative session. Unsupported fonts or source codes refuse without
publishing partial geometry. Invisible and empty nonzero glyph intent is retained.
This stage does not rasterize text or add support for CFF, composite/CID fonts,
Forms/images, transparency, encryption or application editing.
